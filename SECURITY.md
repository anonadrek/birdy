# Security

## Reporting a vulnerability

If you find a security problem in the Birdy app, the website birdy.community or this repository, please email **albin@abrahamssons.se** with:

- what you found and where (app version, page or file),
- how to reproduce it,
- what an attacker could do with it.

Please do not open a public GitHub issue for security problems, and give us a reasonable time to fix the problem before you tell anyone else. We aim to reply within a few working days.

This includes keys or other secrets you find in the repository or its history. Birdy is made by AlbIT AB in Sweden; there is no bug bounty.

## Supported versions

Only the latest version of the app on Google Play and the live website get security fixes.

## Svenska

Hittar du en säkerhetsbrist i appen, på birdy.community eller i repot? Mejla **albin@abrahamssons.se** i stället för att skapa ett publikt ärende, och berätta vad du hittade och hur det går att återskapa.
