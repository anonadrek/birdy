# Release 1.3.0 · Plan 2: Utseendelyftet (Field Journal, palett "Mossa, rost & mässing") — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lyfta Birdys Field Journal-tema till en modernare, mer exklusiv nivå utan att ändra någon funktion: ny palett och typografi app-brett via tokens och delade komponenter, plus nya layouter för sju nyckelskärmar (Identifiera, resultat, Mina arter, Premium + tack, Uppslagsverk, Artprofil, Säsongsstatistik).

**Architecture:** Tre lager i ordning. (1) **Tokens** (`ui/theme/Color.kt`, `Type.kt`, `PaperBackground.kt`, `BirdyTheme.kt`): samma tokennamn, nya värden, så ~70 anropsställen lyfts automatiskt; kontrasten låses av ett test. (2) **Delade komponenter** (`ui/components/`): befintliga komponenter (JournalHeadline, MicroLabel, OrnamentRule, StampSeal, MiniStamp, PlateFrame, HeroImage, BottomNavBar) får nytt utseende med oförändrade signaturer; nya komponenter (`PhotoHero`, `PaperSheet`, knappar, `SectionCard`) läggs till. (3) **Skärmar**: sju skärmar byggs om ovanpå lager 1–2, med bibehållna callbacks, state och semantik. En skärmbildsrigg (Roborazzi/Robolectric) renderar varje skärm på svenska och engelska på datorn så att implementerare och granskare kan se resultatet utan telefon.

**Tech Stack:** Compose Multiplatform 1.8.2 (commonMain), compose-resources, Coil 3, Robolectric + Roborazzi (androidUnitTest, bara för skärmbilder).

**Spec:** `docs/superpowers/specs/2026-09-24-v1-3-release-design.md` §4 (godkända mockups i `docs/superpowers/specs/assets/2026-09-24-v1-3-release/` — `key-screens.html`, `encyclopedia-stats.html`, `palette.html` rad 1).

```kotlin
package se.birdy.app.ui.theme

import androidx.compose.ui.graphics.Color
import kotlin.math.pow
import kotlin.test.Test
import kotlin.test.assertTrue

/** WCAG 2.1 AA: normal text needs ≥ 4.5:1 against its background. Spec 2026-09-24 §4.1. */
class ColorContrastTest {
    private fun channel(c: Float): Double = if (c <= 0.03928f) c / 12.92 else ((c + 0.055) / 1.055).pow(2.4)

    private fun luminance(c: Color): Double = 0.2126 * channel(c.red) + 0.7152 * channel(c.green) + 0.0722 * channel(c.blue)

    private fun contrast(a: Color, b: Color): Double {
        val (hi, lo) = listOf(luminance(a), luminance(b)).sortedDescending()
        return (hi + 0.05) / (lo + 0.05)
    }

    private val papers = mapOf("PaperTop" to PaperTop, "PaperBottom" to PaperBottom, "MossCreme" to MossCreme, "CardPaper" to CardPaper, "SandCreme" to SandCreme)

    @Test
    fun `text tokens reach AA on every paper surface`() {
        val texts = mapOf("TextOnCreme" to TextOnCreme, "MarginaliaInk" to MarginaliaInk, "InkMuted" to InkMuted, "AccentCopper" to AccentCopper, "StampNavy" to StampNavy)
        val failures =
            texts.flatMap { (tn, t) ->
                papers.mapNotNull { (pn, p) -> contrast(t, p).takeIf { it < 4.5 }?.let { "$tn on $pn = $it" } }
            }
        assertTrue(failures.isEmpty(), failures.joinToString("\n"))
    }

    @Test
    fun `light tokens reach AA on dark moss`() {
        val light = mapOf("TextOnHero" to TextOnHero, "AccentCopperLight" to AccentCopperLight, "BrassLight" to BrassLight)
        val failures = light.mapNotNull { (n, c) -> contrast(c, HeroMossDeep).takeIf { it < 4.5 }?.let { "$n on HeroMossDeep = $it" } }
        assertTrue(failures.isEmpty(), failures.joinToString("\n"))
    }

    @Test
    fun `button text reaches AA on rust and brass fills`() {
        assertTrue(contrast(TextOnHero, AccentCopper) >= 4.5)
        assertTrue(contrast(BrassInk, Brass) >= 4.5)
    }
}
```

/**
 * Field Journal headline (1.3.0): upright DM Serif Display, with `*word*` accent segments set
 * in DM Serif Display *italic* in [accentColor]. (1.2 used rotated Caveat for the accent;
 * handwriting now lives only in marginalia and sub-lines — spec 2026-09-24 §4.2.)
 */
@OptIn(ExperimentalLayoutApi::class)
@Composable
fun JournalHeadline(
    text: String,
    modifier: Modifier = Modifier,
    fontSize: TextUnit = 30.sp,
    plainColor: Color = TextOnCreme,
    accentColor: Color = AccentCopper,
) {
    val segments = parseJournalHeadline(text)
    val serif = rememberDmSerifDisplay()

    FlowRow(modifier = modifier.semantics(mergeDescendants = true) {}) {
        segments.forEach { seg ->
            Text(
                text = seg.text,
                color = if (seg is HeadlineSegment.Accent) accentColor else plainColor,
                fontFamily = serif,
                fontStyle = if (seg is HeadlineSegment.Accent) FontStyle.Italic else FontStyle.Normal,
                fontWeight = FontWeight.Normal,
                fontSize = fontSize,
                letterSpacing = (-0.01).em,
            )
        }
    }
}
