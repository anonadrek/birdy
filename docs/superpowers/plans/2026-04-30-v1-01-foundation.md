# Birdy Bird Scanner — Plan 1: Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap a Kotlin Multiplatform + Compose Multiplatform project with the module structure declared in the v1 design spec, plus linting, a smoke unit test, and a green GitHub Actions CI. Outcome: an empty "Birdy" app installs on Android and shows a placeholder welcome screen.

**Architecture:** KMP shared modules (`shared/domain`, `shared/data`, `shared/ml`, `shared/content`) consumed by a `composeApp` module that hosts the Compose Multiplatform UI. `androidApp` is the Android entry point. `iosApp` is a skeleton that compiles but isn't wired up — iOS comes later. SQLDelight is the local DB framework; TFLite is the ML runtime (interface only in this plan).

**Tech Stack:** Kotlin 2.1.20, Compose Multiplatform 1.7.3, AGP 8.7.3, Gradle 8.11, SQLDelight 2.0.2, JUnit 5.11.3, ktlint 12.1.2, detekt 1.23.7, GitHub Actions.

> **Version note:** Versions above are stable as of late 2025. Before Task 1, run `./gradlew --version` and check https://kotlinlang.org/docs/releases.html if you want to bump to the latest patch versions. Don't jump major versions without re-reading the plan.

```kotlin
package se.birdy.ml

/**
 * Image bytes in a platform-neutral form: raw bytes plus dimensions.
 * The actual classifier preprocesses internally.
 */
data class ImageInput(
    val bytes: ByteArray,
    val widthPx: Int,
    val heightPx: Int,
    val rotationDegrees: Int = 0,
) {
    override fun equals(other: Any?): Boolean =
        other is ImageInput &&
            bytes.contentEquals(other.bytes) &&
            widthPx == other.widthPx &&
            heightPx == other.heightPx &&
            rotationDegrees == other.rotationDegrees

    override fun hashCode(): Int {
        var result = bytes.contentHashCode()
        result = 31 * result + widthPx
        result = 31 * result + heightPx
        result = 31 * result + rotationDegrees
        return result
    }
}

data class ClassificationResult(
    val speciesId: String,
    val confidence: Float,
)

data class Classification(
    val results: List<ClassificationResult>,
) {
    fun top(): ClassificationResult? = results.maxByOrNull { it.confidence }

    fun sortedByConfidenceDescending(): List<ClassificationResult> =
        results.sortedByDescending { it.confidence }
}

expect class BirdClassifier {
    suspend fun classify(image: ImageInput): Classification
    fun close()
}
```

### Task 10: Add GitHub Actions CI

- [ ] **Step 1: Write `.github/workflows/ci.yml`**

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build:
    name: Build & test
    runs-on: ubuntu-latest
    timeout-minutes: 25
    steps:
      - uses: actions/checkout@v4

      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      - name: Set up Gradle cache
        uses: gradle/actions/setup-gradle@v4

      - name: ktlint
        run: ./gradlew ktlintCheck --stacktrace

      - name: detekt
        run: ./gradlew detekt --stacktrace

      - name: Unit tests (shared modules)
        run: ./gradlew :shared:domain:jvmTest :shared:ml:jvmTest --stacktrace

      - name: Assemble Android debug APK
        run: ./gradlew :androidApp:assembleDebug --stacktrace

      - name: Upload debug APK
        uses: actions/upload-artifact@v4
        with:
          name: birdy-debug-apk
          path: androidApp/build/outputs/apk/debug/*.apk
          retention-days: 14
          if-no-files-found: error
```

## Notes for Plan 2 (carry-forward context)

- The empty `sqldelight { databases { ... } }` block in `shared/data/build.gradle.kts` will register `BirdyDatabase` here.
- The `BirdClassifier` interface is locked — Plan 4's TFLite implementation must satisfy it without changing the signature.
- Module-level package convention is `se.birdy.<module>`. Stick with it.
- All UI code lives in `composeApp` (Compose Multiplatform), not in `androidApp`. `androidApp` only hosts `MainActivity`.
- The Mossbädd palette tokens in `theme/Color.kt` are the source of truth. New screens read from `MaterialTheme.colorScheme.*` — do not hardcode hex values outside `Color.kt`.
- Plan 3 will: (a) add the real Crimson Pro `.ttf` to `composeApp/src/commonMain/composeResources/font/` and swap `FontFamily.Serif` for it in `Type.kt`, (b) build the actual hero zone with `Brush.verticalGradient`, (c) build stat cards and bottom navigation. None of those exist yet.
