## Steg 1 — T8 ML preprocessing-diagnos (device-dump + diff)

### 1a. Installera senaste debug-bygget

```bash
./gradlew :androidApp:installDebug
"$ADB" shell am start -n se.birdy.android/.MainActivity
```

### 1b. Kör DiagnosticsScreen

På telefonen:
1. Genomför onboarding om det är fresh install (Skip → Listen).
2. Tryck på **Encyclopedia**-fliken (Archive-listan).
3. Tryck på overflow-menyn (top-right).
4. Välj **"ML diagnos"**.
5. Tryck **"Run diagnostic"**. Vänta ~5 s tills tre sektioner visas på skärmen.
6. Tryck back.

### 1c. Pull dumpen

```bash
mkdir -p docs/superpowers/research/preprocess-dumps/
"$ADB" shell run-as se.birdy.android ls files/ | grep preprocess_dump
# Notera det senaste filnamnet, t.ex. preprocess_dump_1747987200000.txt

"$ADB" shell run-as se.birdy.android cat files/preprocess_dump_LATEST.txt \
  > docs/superpowers/research/preprocess-dumps/2026-05-16-device-sm-s918b.txt
```

### 1d. Generera desktop-dump

```bash
cd tools/ml-eval
uv run python -m birdy_eval dump-mid-row \
  --model ../../shared/ml/src/commonMain/composeResources/files/ml/aiy_birds_v1.tflite \
  --mapping ../../shared/ml/src/commonMain/composeResources/files/ml/aiy_to_qid.json \
  --photos-dir ../../composeApp/src/androidMain/assets/benchmark/ \
  --out ../../docs/superpowers/research/preprocess-dumps/2026-05-16-desktop.txt
cd -
```

### 1e. Diff + analys

```bash
diff -u docs/superpowers/research/preprocess-dumps/2026-05-16-desktop.txt \
        docs/superpowers/research/preprocess-dumps/2026-05-16-device-sm-s918b.txt | head -80
```

**Skicka diffen till Claude.** Hen läser den, fyller i Results-tabellen i `2026-05-16-ml-preprocessing-diagnos.md`, väljer Path A (S-sized root-cause-fix) eller Path B (defer + sänk NoBird-threshold 0.10 → 0.05), och dispatchar implementer per plan T8.A.* eller T8.B.*.

### 3a. Bumpa versionCode + versionName

```bash
# Claude gör detta i androidApp/build.gradle.kts: versionCode = 110, versionName = "1.0.0-rc2"
```

### 3b. Bygg signed AAB

```bash
./gradlew :androidApp:bundleRelease
ls -lh androidApp/build/outputs/bundle/release/androidApp-release.aab
```

### 3c. Installera via bundletool (samma flöde som Plan 6a T15)

```bash
# Pre-req: keystore + passwords i env
java -jar tools/bundletool-all-1.18.1.jar build-apks \
  --bundle=androidApp/build/outputs/bundle/release/androidApp-release.aab \
  --output=/tmp/birdy.apks \
  --ks=keystore/birdy-upload.keystore \
  --ks-key-alias=birdy-upload \
  --ks-pass=pass:$BIRDY_KEYSTORE_PASSWORD \
  --key-pass=pass:$BIRDY_KEY_PASSWORD

java -jar tools/bundletool-all-1.18.1.jar install-apks --apks=/tmp/birdy.apks
"$ADB" shell am start -n se.birdy.android/.MainActivity
```

### 3d. Purchase-flow (Yearly)

Förutsättning: testanvändaren är på Closed Testing-spåret (T0).

2. Google billing sheet öppnar → välj test-kort → completera köpet.
3. Tillbaka i appen → PremiumState ska flippa till `Active(YEARLY)`.
4. Quit appen.
5. Re-launch → ingen Premium-modal; Settings visar "Premium" istället för "Become a field member".
