## Pre-3 — Play License Key (ny prereq, måste göras INNAN ombyggnad)

`BIRDY_PLAY_LICENSE_KEY` är inte satt i `~/.gradle/gradle.properties`. Det är OK för debug-builds (check skippar via `BuildConfig.DEBUG`), men release-AAB:n kastar vid start. Nyckeln är tillgänglig i Play Console **utan** att du behöver ladda upp någon AAB först:

1. Sign in på Play Console (efter T0.1 godkännande).
2. Skapa app-entry "Birdy" om den inte redan finns.
3. **Monetization Setup → Licensing → Public licensing key** → kopiera hela base64-strängen.
4. Lägg till i `~/.gradle/gradle.properties`:
   ```properties
   BIRDY_PLAY_LICENSE_KEY=<inklistrad base64 utan radbrytningar>
   ```
5. Verifiera att den lästes in:
   ```bash
   grep BIRDY_PLAY_LICENSE_KEY ~/.gradle/gradle.properties | head -c 60; echo "..."
   ```
6. Återgå till 3b för att bygga om AAB:n med nyckeln embeddad i BuildConfig.

### 3c. Installera via bundletool (samma flöde som Plan 6a T15)

```bash
# Pre-req: keystore + passwords i env (gradle.properties laddar dessa automatiskt vid build,
# men bundletool körs utanför gradle så vi sätter dem manuellt här om de inte är i shell-env).
# Verifiera först:
echo "BIRDY_KEYSTORE_PATH=$BIRDY_KEYSTORE_PATH"  # ska vara C:/Users/abbea/keys/birdy-upload.jks
echo "BIRDY_KEY_ALIAS=$BIRDY_KEY_ALIAS"          # ska vara birdy-upload

java -jar "C:/Users/abbea/tools/bundletool-all.jar" build-apks \
  --bundle=androidApp/build/outputs/bundle/release/androidApp-release.aab \
  --output=/tmp/birdy.apks \
  --ks="$BIRDY_KEYSTORE_PATH" \
  --ks-key-alias="$BIRDY_KEY_ALIAS" \
  --ks-pass=pass:"$BIRDY_KEYSTORE_PASSWORD" \
  --key-pass=pass:"$BIRDY_KEY_PASSWORD"

java -jar "C:/Users/abbea/tools/bundletool-all.jar" install-apks --apks=/tmp/birdy.apks
"$ADB" shell am start -n se.birdy.android/.MainActivity
```
