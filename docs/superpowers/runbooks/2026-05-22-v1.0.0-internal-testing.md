# Internal Testing hand-off — Birdy Bird Scanner v1.0.0

> Skapad 2026-05-22 som del av Plan 6b3 T25. Beskriver hur AAB:n från
> `:androidApp:bundleRelease` släpps till Google Play Internal Testing och
> hur Billing v8 IPC verifieras runtime.

## Förkrav

- Play Console-konto approved (personligt, Albin — bytte till AB-bolaget post-launch via Account Transfer).
- App entry "Birdy Bird Scanner" skapad i Play Console med `applicationId = se.birdy.android`.
- In-app products `birdy_yearly` + `birdy_lifetime` konfigurerade i Play Console → Monetize → Subscriptions / In-app products.
- License testers tillagda (din Gmail + ev. kollegor) i Play Console → Setup → License testing.
- `~/.gradle/gradle.properties` har:
  - `BIRDY_UPLOAD_STORE_FILE=<absolute path till keystore>`
  - `BIRDY_UPLOAD_STORE_PASSWORD=…`
  - `BIRDY_UPLOAD_KEY_ALIAS=…`
  - `BIRDY_UPLOAD_KEY_PASSWORD=…`
  - `BIRDY_PLAY_LICENSE_KEY=<RSA public key från Play Console → Setup → Licensing>`

## Build signed AAB

```bash
export JAVA_HOME="C:/Java/OpenJDK21U-jdk_x64_windows_hotspot_21.0.11_10/jdk-21.0.11+10"
export PATH="$JAVA_HOME/bin:$PATH"
./gradlew :androidApp:bundleRelease
```

Output: `androidApp/build/outputs/bundle/release/androidApp-release.aab`.

Smoke-testa lokalt via bundletool först:

```bash
java -jar bundletool-all-1.18.1.jar build-apks \
    --bundle=androidApp/build/outputs/bundle/release/androidApp-release.aab \
    --output=birdy-release.apks --connected-device
java -jar bundletool-all-1.18.1.jar install-apks --apks=birdy-release.apks
```

Cold-start → ingen `PremiumBillingClient`-init-crash, ingen R8/TFLite-crash i `adb logcat -d`.

## Upload till Internal Testing

1. Play Console → Birdy → **Test and release → Internal testing → Create new release**.
2. Upload `androidApp-release.aab`.
3. Release name: `1.0.0 (112)` (versionCode måste matcha `androidApp/build.gradle.kts`).
4. Release notes (SV + EN — copy från Plan 6b3 design-spec §15 eller skriv fresh):

   **SV:**
   > Första publika versionen av Birdy. Foto-ID, audio-ID via BirdNET, dagbok med 25 fält-märken, uppslagsverk över 839 europeiska arter — och Premium-funktioner (PDF Field Journal-export, säsongsstatistik, 10 extra fält-märken) öppna gratis under closed testing.

   **EN:**
   > First public release of Birdy. Photo ID, audio ID via BirdNET, journal with 25 field marks, encyclopedia of 839 European species — and Premium features (PDF Field Journal export, season statistics, 10 extra field marks) free during closed testing.

5. Save → **Review release** → fixa varningar om någon.
6. **Roll out to Internal testing** — tar 5–30 min innan opt-in-länken funkar.
7. Skicka opt-in-länken (Play Console → Internal testing → Testers tab → "Copy link") till license testers + bjud in dig själv.

## Verifiera Billing v8 IPC (deferred från Plan 6b1)

På testenheten med license-tester-konto inloggat:

1. Cold-start → ingen crash i `PremiumBillingClient.android.kt:onBillingSetupFinished`.
2. Premium screen → "Bli Premium" → välj YEARLY → genomför testpurchase (gratis för license testers).
3. Kontrollera att `effectivePremiumActive` flippar → `premium_field_member` welcome-sheet poppar upp.
4. Försök igen för LIFETIME — separat productId, samma flöde.
5. Settings → **Restore Purchases** efter app-uninstall + reinstall → state ska återställas.
6. Logcat (`adb logcat -s PremiumBilling`) ska visa "RSA SHA1 verify PASSED" från `verifyPurchase()` (BuildConfig.PLAY_LICENSE_KEY måste vara satt).

## Verify Premium-open-for-launch funkar

Closed-testing testers ska få Premium gratis utan att purchase:n går igenom (PREMIUM_OPEN_FOR_LAUNCH=true tvingar `premiumOverride = Active(LIFETIME)` i MainActivity).

Verifiering:
- Öppna appen som testanvändare som ALDRIG köpt något → Archive ska visa "Export Field Journal" CTA, Lifelist ska visa LiveStatsPreview, Badges ska visa premium-sektionens 2×5-grid.
- Inga Premium-pay-walls / Bottom-sheets ska visas (PremiumGate redan rivet i ListenLauncher).

## Post-Internal Testing → Closed Testing (14d)

När Internal Testing fungerar:

1. Play Console → **Closed testing → Create track** (eller "Promote release" från Internal Testing).
2. Reuse samma AAB — Play promotes tracks utan ny bygg.
3. **14-dagars closed-testing-klocka börjar tickar nu** (Google's krav för förstagångsuppladdare innan production).
4. Under 14d: samla feedback, fixa kritiska buggar, rulla ut hotfix-AAB med versionCode++ vid behov.
5. Efter 14d + ≥20 testers + activity-tröskel → eligible för production-release.

## Säkerhetscheck före upload

- [ ] `PREMIUM_DEBUG_FORCE_ACTIVE=false` i `release {}` (build.gradle.kts:95). Endast `debug {}` ska någonsin sätta true.
- [ ] `PREMIUM_OPEN_FOR_LAUNCH=true` i `defaultConfig` är **intentional** under closed-testing-perioden. Bytt till `false` + versionCode++ när Billing v8 monetization aktiveras i framtida release.
- [ ] AAB-storlek < 150 MB (Play limit). Audio model (~6 MB) + TFLite photo model (~4 MB) + 839 species YAMLs (~5 MB packed) ska väl rymmas.
- [ ] AAB signed med upload-key (inte debug-key). Check via `keytool -printcert -jarfile androidApp-release.aab`.
- [ ] Data Safety form ifylld i Play Console (privacy-promise = "Almost nothing collected"). Kontent från `docs/play-store/data-safety-form.md`.
